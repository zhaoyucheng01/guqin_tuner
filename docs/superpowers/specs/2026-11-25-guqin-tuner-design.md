# 古琴调音器（Guqin Tuner）设计规格说明书

日期：2026-11-25
项目标识：`guqin-tuner`（中文名：古琴调音器 / 古琴調音器）

## 1. 目标与范围

本项目面向**手机端浏览器及 PWA 使用场景**，构建一款零构建、零第三方依赖的纯前端古琴调音器网页应用。

### 核心范围
- **麦克风实时拾音调音**：专注高精度实时测频与直观仪表反馈，不包含参考音发声功能。
- **纯自动识弦**：拨响任意琴弦后，自动显示最近十二平均律音名、频率与音分偏差，并同步高亮当前调式下最匹配的弦位。
- **古琴多调式与移调**：内置 6 种传统常用古琴调式预设，支持 `-6` 至 `+6` 半音整体移调，以及 `A4 = 430–450 Hz` 基准频率调节。
- **移动端优先体验**：宣纸墨绿雅致国风，手机竖屏一屏紧凑布局，支持简繁中文切换、Screen Wake Lock 屏幕常亮、`localStorage` 自动保存设置及 PWA 安装到手机桌面。

### 明确不做（YAGNI）
- 不做点击琴弦发声/标准音播放功能。
- 不做手动锁弦模式或自定义单弦音高编辑。
- 不引入打包构建工具（Vite/Webpack）或外部第三方 JS 库。

## 2. 视觉与交互设计

### 2.1 色彩与风格
延续 `gongche_tuner` 的雅致国风体系：
- 页面宣纸底色：`#f4f2ec`
- 卡片暖白底色：`#fffefa`
- 主墨色文字：`#26332e`，次要灰绿文字：`#77817b`
- 边框线条：`#e6e3d9`
- 主题墨绿：`#29483d`（柔和浅绿背景 `#e8eee9`）
- 雅金强调色：`#a27c3e`（高亮弦位与焦点边框）
- 准音翠绿：`#2e7d5b`（进入 `±5 音分` 准音区时高亮反馈）
- 偏低/偏高提示色：偏低使用沉稳靛蓝/暖金，偏高使用温润赭红 `#b5563c`

### 2.2 手机竖屏一屏布局（360px–430px 视口）
页面采用纵向 Flex 一屏布局（`100dvh`，适配 `env(safe-area-inset-top/bottom)`），自上而下分为四个紧凑区块：

1. **顶部栏**
   - 左：应用标题「古琴调音器」（繁体「古琴調音器」）
   - 右：简/繁切换胶囊按钮 + 麦克风「开始调音 / 暂停」主开关按钮
2. **上半区：实时读数与半圆表盘**
   - 左列：大号音名（如 `C2`、`E♭4`，升降号上标、八度下标）+ 实时频率（如 `65.4 Hz`）+ 偏差提示（如 `-4 音分 · 偏低` / `准音 ✓` / `+6 音分 · 偏高` / `待机中`）
   - 右列：SVG 半圆形指针表盘，刻度覆盖 `-50` 至 `+50` 音分，中央 `±5 音分` 为准音绿弧，指针带平滑阻尼动画；落入准音区时指针、中心圆点与音名同步亮绿。
3. **中下主区（左控制 + 右七弦）**
   - **左区**：
     - `A4 基准调节`：`[-]` `440 Hz` `[+]`（步进 1 Hz，范围 430–450 Hz；点击中间数值重置为 440 Hz）。
     - 淡墨竹叶 SVG 水印装饰。
     - `降半音` / `升半音` 快捷移调双按钮（范围 `-6` 至 `+6` 半音）。
   - **右区（七弦竖排指示列）**：
     - 从上到下排列一弦至七弦共 7 个圆形徽章（贴合面对古琴的直观视角与参考图布局），圆内显示移调后的目标音名（如 `C`、`D`、`F`、`G`、`A`、`C`、`D`），左侧或角标以小字标注弦序（一~七）。
     - 右侧伴随竖排半音间距圆点示意（每两弦之间的圆点数量对应半音数，弦位处为实心点）。
     - 拨弦时自动高亮最匹配的目标弦（放大与金色/绿色光晕）；静音超时后自动回归常规态。
4. **底部定弦调式卡片 + 调式抽屉**
   - 卡片左上方显示当前调式与调号（如 `正调定弦 · 1=F`），右上方显示移调角标（如 `-1`、`+2`，为 `0` 时隐藏；点击角标可一键归零）。
   - 卡片下方横向展示七弦简谱散音（带上下低音点，如正调 `5̣̣ 6̣̣ 1̣ 2̣ 3̣ 5̣ 6̣`）。
   - 点击卡片弹出底部抽屉（Bottom Sheet），列表展示全部 6 种调式及其改弦说明与代表曲目，选择后立即生效并收起抽屉。

## 3. 古琴调式数据与自动识弦规则

### 3.1 内置 6 种古琴调式预设
所有调式以标准十二平均律 MIDI 音高为基准（`A4 = MIDI 69`）：

| ID | 简体名称 | 繁体名称 | 调号 | 改弦说明 | 七弦标准 MIDI（一至七弦） | 标准散音名 | 简谱（含低音点数） |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `zhengdiao` | 正调 | 正調 | `1=F` | 标准定弦 | `[36, 38, 41, 43, 45, 48, 50]` | `C2 D2 F2 G2 A2 C3 D3` | `5(-2) 6(-2) 1(-1) 2(-1) 3(-1) 5(-1) 6(-1)` |
| `ruibin` | 蕤宾调 | 蕤賓調 | `1=B♭` | 紧五弦 | `[36, 38, 41, 43, 46, 48, 50]` | `C2 D2 F2 G2 B♭2 C3 D3` | `2(-2) 3(-2) 5(-2) 6(-2) 1(-1) 2(-1) 3(-1)` |
| `manjiao` | 慢角调 | 慢角調 | `1=C` | 慢三弦 | `[36, 38, 40, 43, 45, 48, 50]` | `C2 D2 E2 G2 A2 C3 D3` | `1(-1) 2(-1) 3(-1) 5(-1) 6(-1) 1(0) 2(0)` |
| `qingshang` | 清商调 | 清商調 | `1=E♭` | 紧二五七 | `[36, 39, 41, 43, 46, 48, 51]` | `C2 E♭2 F2 G2 B♭2 C3 E♭3` | `6(-2) 1(-1) 2(-1) 3(-1) 5(-1) 6(-1) 1(0)` |
| `manshang` | 慢商调 | 慢商調 | `1=F` | 慢二弦 | `[36, 36, 41, 43, 45, 48, 50]` | `C2 C2 F2 G2 A2 C3 D3` | `5(-2) 5(-2) 1(-1) 2(-1) 3(-1) 5(-1) 6(-1)` |
| `wuyi` | 无射调 | 無射調 | `1=B♭` | 紧五慢一 | `[34, 38, 41, 43, 46, 48, 50]` | `B♭1 D2 F2 G2 B♭2 C3 D3` | `1(-2) 3(-2) 5(-2) 6(-2) 1(-1) 2(-1) 3(-1)` |

### 3.2 频率与音分计算
- 目标 MIDI：`targetMidi = baseMidi + transpose`（`transpose ∈ [-6, +6]`）
- 目标频率：$f = f_{A4} \times 2^{(\text{midi} - 69) / 12}$
- 实时连续 MIDI：$m = 69 + 12 \times \log_2(f_{\text{detected}} / f_{A4})$
- 最近半音 MIDI：`nearestMidi = Math.round(m)`，表盘音分偏差：`cents = (m - nearestMidi) * 100`（范围 `[-50, +50]`）。

### 3.3 纯自动识弦匹配逻辑
- **表盘显示**：始终按 `nearestMidi` 显示当前真实音名、八度、频率与音分指针。
- **右侧七弦匹配**：计算检测到的连续 MIDI `m` 与当前调式 7 根目标弦 MIDI 的绝对差值，找出最小差值对应的所有弦索引（若存在同音弦如慢商调的一、二弦，则同时返回两个索引）。
  - 当最近弦距离在 `±1.5` 个半音（`±150 音分`）以内时，高亮对应弦位；若偏差绝对值 `≤ 5 音分`，判定为**准音**。
  - 若检测音高超出七弦散音范围（例如弹奏高音泛音或按音，离最近目标弦超过 1.5 半音），顶部表盘依然正常测频，右侧七弦不误高亮。

## 4. 手机端古琴低频拾音架构

### 4.1 音频采集链路（`src/audio.js`）
- 调用 `navigator.mediaDevices.getUserMedia` 时显式配置：
  ```js
  audio: {
    echoCancellation: false,
    noiseSuppression: false,
    autoGainControl: false
  }
  ```
- 音频处理图：`MediaStreamAudioSourceNode` → `BiquadFilterNode`（`type = "lowpass"`, `frequency = 1000`, `Q = 0.707`，削减高频指甲噪声与人声高频）→ `AnalyserNode`（`fftSize = 4096`，时域浮点采样 `getFloatTimeDomainData`）。
- 开启拾音时尝试申请 `navigator.wakeLock.request("screen")` 保持屏幕常亮；暂停或页面切至后台（`document.hidden === true`）时自动停止拾音并释放 `MediaStream` 轨道与 Wake Lock。

### 4.2 MPM 音高检测算法（`src/pitch.js`）
针对古琴低频散音（低至 ~50 Hz）及手机麦克风低频衰减（二倍频能量常高于基频）的特点，实现 **McLeod Pitch Method（MPM）**：
1. **RMS 静音门限**：计算当前帧均方根能量 `rms`，低于门限（默认 `0.008`）直接返回 `null`（静音）。
2. **有效周期区间**：限定检测频率范围 `45 Hz – 1200 Hz`（覆盖无射调降半音一弦低音及常用泛音/按音），对应延迟区间 `lag ∈ [Math.floor(sampleRate / 1200), Math.ceil(sampleRate / 45)]`。
3. **归一化平方差函数（NSDF）**：
   $$n'(\tau) = \frac{2 \sum_{j=0}^{W-1-\tau} x_j x_{j+\tau}}{\sum_{j=0}^{W-1-\tau} (x_j^2 + x_{j+\tau}^2)}$$
4. **防八度误判峰值选择**：
   - 遍历 `n'(τ)` 找出所有正值区间内的局部极大值（key maxima）。
   - 计算全局最高峰 `maxPeak`，设定动态阈值 `threshold = 0.88 * maxPeak`（且 `maxPeak >= 0.55` 才视为有效清晰乐音，过滤环境白噪声）。
   - 取**第一个**达到 `threshold` 的局部极大值索引 `bestLag`（天然避免错选高八度或低八度倍周期）。
5. **抛物线插值**：利用 `(bestLag - 1, bestLag, bestLag + 1)` 三点做二次抛物线拟合，输出精确浮点延迟 `refinedLag`，最终频率 `freq = sampleRate / refinedLag`。
6. **时间域稳定器（`PitchSmoother`）**：
   - 维护最近 5 帧有效频率的滑动窗口，取中位数过滤拨弦瞬态毛刺；若新频率与当前稳定频率跳变超过 80 音分（换弦），快速清空旧窗口以保证切弦响应灵敏。
   - 静音后保留最后一次有效读数 1500 ms，随后平滑回到待机状态。

## 6. 错误处理与边界场景

| 场景 | 处理方式 |
| :--- | :--- |
| 非 HTTPS 且非 `localhost` 访问 | 检测 `window.isSecureContext`，顶部状态条清晰提示「麦克风功能需要在 HTTPS 网址或本地服务下使用」，禁用开麦按钮避免误报错 |
| 浏览器不支持 `getUserMedia` | 提示当前浏览器不支持麦克风拾音，建议使用系统自带 Safari / Chrome 打开 |
| 用户拒绝麦克风权限（`NotAllowedError`） | 清晰中文提示前往浏览器地址栏或系统设置中允许麦克风权限，允许重新点击尝试 |
| 未检测到麦克风设备（`NotFoundError`） | 提示未检测到可用麦克风设备 |
| 手机切后台 / 锁屏 | 监听 `visibilitychange`，自动暂停拾音、释放麦克风流与 Wake Lock，返回前台可一键继续 |
| 本地存储不可用（隐私模式） | 所有 `localStorage` 读写均以 `try/catch` 保护，降级为内存态运行，不阻塞页面 |

## 7. 持久化配置

`localStorage` 键名：`guqin-tuner-settings-v1`，保存 JSON 字段：
- `tuningId`：当前调式 ID（默认 `"zhengdiao"`）
- `transpose`：整体移调半音数（默认 `0`，范围 `-6` 至 `+6`）
- `a4`：A4 基准频率（默认 `440`，范围 `430` 至 `450`）
- `language`：界面语言（默认 `"zh-CN"`，可选 `"zh-TW"`）

## 8. 验证与测试策略

1. **自动化单元测试（`node --test`）**：
   - `tests/tunings.test.js`：验证全部 6 种调式目标频率、升降半音、A4 校准、最近音名/音分计算及慢商调同音弦匹配。
   - `tests/pitch.test.js`：使用 48 kHz 采样率合成波形测试：
     - 纯正弦波：`58.27 Hz`（B♭1）、`65.41 Hz`（C2）、`146.83 Hz`（D3）、`440.00 Hz`（A4），误差需在 `±2 音分` 以内。
     - 模拟手机麦克风低频滚降的古琴多泛音波形（基频 `65.41 Hz` 幅度 `0.35`，二倍频 `130.81 Hz` 幅度 `1.0`，三倍频 `196.22 Hz` 幅度 `0.6`），验证依然准确识别为 `65.41 Hz`（误差 `±2 音分` 以内），不跳高八度。
     - 纯静音与低幅度白噪声，验证返回 `null`。
2. **本地端到端与移动端视口检查**：
   - 启动本地静态 HTTP 服务，验证移动端竖屏（390×844）一屏无溢出、调式抽屉切换、升降半音与 A4 调节、简繁切换、刷新后设置恢复以及控制台无报错。
